simtest-funnel — interactive demo

Runs the funnel trajectory comparison entirely in your browser via WebAssembly (@simtest-js/funnel). Two CSV files (time,x,y,z) — a reference and a noisy test — are compared column-by-column with tolerances atolx = atoly = 0.1.
