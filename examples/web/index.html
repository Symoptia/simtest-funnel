simtest-funnel — interactive demo

Runs the funnel trajectory comparison entirely in your browser via WebAssembly (@simtest-js/funnel). Two parts: synthetic signals with known differences, and real weather forecasts compared with what the weather model later said happened.

← back to documentation

Two CSV files (time,x,y,z) — a reference and a noisy test — are compared column-by-column with tolerances atolx = atoly = 0.1.

Reference and test data generated from the formulas in tests/python/tools/demo_signals.py.
